# OmniPDF AI coding guidance

This project is a React + TypeScript + Vite + Tailwind PDF application. Preserve existing document workflows and functional behavior during UI improvements.

Before frontend redesign or polish, consult:
- [Impeccable](https://github.com/pbakaus/impeccable) for layout, typography, color, accessibility, and responsive audits.
- [Taste Skill](https://github.com/leonxlnx/taste-skill) for purposeful, non-generic visual direction.
- [Motion Skill](https://github.com/freshtechbro/claudedesignskills/blob/main/.claude/skills/motion-framer/SKILL.md) for restrained, accessible React motion patterns.

See [design skills guide](docs/design-skills/README.md) for integration notes and installation references. These are external skill references; they are not installed as application dependencies.
